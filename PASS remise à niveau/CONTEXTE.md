# PASS : remises à niveau 3A FISA

Trois modules de remise à niveau en début de 3A, qui servent de prérequis aux cours principaux.

## `électronique/` (SYS3043)
- `cours 2026/` (Sulaf Alkasm) : cours de mise à niveau, chapitres 1 à 5 (dipôles, lois de Kirchhoff, théorèmes généraux, diodes, diagramme de **Bode**), filtres passifs, présentation de la carte **Arduino** ; TD Bode ; TP n°2 diode (redressement mono-alternance, filtrage) ; TP Arduino.
- `Généralités/` : TD numération (bases 10/2/16, conversions) avec corrigés, algèbre de Boole (SYS2041), code de Gray, théorème de Thévenin, filtrage actif/passif (cours CNAM complet), TD filtre du 1er ordre.
- Restés sur Moodle : cours « Théorèmes généraux » et SYS2041-CM1 (`.ppt`), TP Arduino (`.docx`).

## `informatique/` (INF3036) : PASS Java
- **Enseignante** : Khadija SLIMANI (TP N. Aouani).
- `Support cours et exercices/` : séance 1 (algorithmique, variables, types, conditions, boucles), séances 3-4 (tableaux, chaînes, complexité, recherche séquentielle/dichotomique, tri à bulles), séances 5-6 (récursivité, glouton, diviser pour régner, pile LIFO, file FIFO), séances 7-8 (tableaux dynamiques, listes chaînées, arbres binaires). **TP1 à TP9** suivent les séances.
- `Projet Java/` : projet **Sokoban** (jouer au jeu + résolution algorithmique).

## `maths/` (PLU3198)
- `Rappel mathématiques/` (support d'Abdelrhani DAOUDI) : partie 1, primitives et intégrales, parité, périodicité, changement de variable, intégration par parties ; partie 2, polynômes, fractions rationnelles, **décomposition en éléments simples** (utile pour Laplace). Version poly + slides complètes / réduites.
- `TDs/` : TD PASS 3A (fonctions périodiques, coefficients de type Fourier) + corrigé des exercices non traités.
