# Bases de données (INF3031), 3A FISA

- **Enseignante** : Safa BETTOUMI ZOGHLAMI.
- **Outil** : Oracle SQL Developer + Oracle XE (guides d'installation Windows et macOS dans `Installation d'Oracle SQL Developer/`).

## Supports
- `Cours/`
  - **CM1** : introduction aux bases de données (rôle d'un SGBD, modélisation, modèle Entités-Associations / MERISE, passage au modèle relationnel).
  - **CM2** : SQL (LDD : CREATE/ALTER/DROP et contraintes ; LMD : INSERT/UPDATE/DELETE ; interrogation : SELECT, jointures, agrégats, GROUP BY/HAVING, sous-requêtes).
- `Travaux pratiques/`
  - **TP1** : modèle Entités-Associations (MERISE) à partir d'un cahier des charges (exemple de la bibliothèque).
  - **TP2** : requêtes SQL sur une base « cinéma » (Artiste, Cinema, Film, Role, Salle, Seance). Le script `Cinema_Data.sql` est resté sur Moodle.
