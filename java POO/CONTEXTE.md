# Programmation orientée objet en Java (INF3132), 3A FISA

- **Supports** de Felicia IONASCU, Siba HAIDAR, Aylen RICCA (cours 1 à 4) + une version « séances » en 3 parties (fichiers `0X_..._FR.pdf`).

## Progression
| Dossier | Contenu |
|---|---|
| `Course 1 part 1/` | Paradigmes de programmation, principes de la POO, classes et objets, bases de Java, JVM/JDK, **UML** (diagramme de classes) ; séance 1 : fondamentaux, première hiérarchie polymorphe |
| `Course 1 Part 2/` | Abstraction, allocation mémoire (pile/tas), **héritage**, **encapsulation**, masquer l'implémentation |
| `Course 2/` | **Polymorphisme**, classes abstraites vs **interfaces**, **exceptions** ; séance 2 : Comparable/Comparator, itérateurs, premier design pattern |
| `Course 3/` | Relations entre classes (association, agrégation, composition), **généricité**, **collections** (List, Set, Map), entrées/sorties ; séance 3 : génériques et collections |
